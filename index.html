⚙️ Pipeline Overview

1 Data Ingestion 2 Preprocessing 3 Model Training 4 Evaluation 5 Registry 6 Deployment
  • Data: 5,550 HSI patches (15×15×155) from 4 nutrient conditions
  • Preprocessing: Savitzky-Golay smoothing → SNV normalization → PCA (155→20 bands)
  • Model: Deep Spectral-Spatial CNN with 123k parameters
  • Deployment: FastAPI REST API with automatic preprocessing
  • Format support: Raw .tiff and preprocessed .npy files
